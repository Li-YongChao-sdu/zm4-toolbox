# 魔渊回放研究室 · 试用版（2026-10-24）

适用于本期v5870魔渊第九层。网页在本地运行，不需要安装Python。游戏内功能需要Fiddler替换主文件；本包不包含Fiddler与FFDec。

## 1. 加载研究室主文件

Fiddler AutoResponder启用规则，匹配：

`EXACT:https://sda.4399.com/4399swf/upload_swf/ftp15/csya/20150127/1/v5870.swf`

替换为解压目录中的 `v5870.moyuan_json_lab.swf` 的完整路径。启用未匹配请求正常通过，然后关闭旧游戏页面、重新打开游戏。游戏右上角应出现研究室控制面板。此包直接连接原服务器，不需要启动旧实验TCP代理。

## 2. 导出自己的配置和候选录像

在主城打开自身背包，点击“读取自身快照”，核对提示的生命、攻击、魔法和闪避，再“导出自身快照”。包含剑意等上下文与原生面板校验值。换装后退出存档再进入，重新读取。第一/第二心法分别切换、重进、读取并另存，不能混用。

点击“批量读取榜单”，选择角色、份数或排名区间，开始读取；等待提示完成再导出。导出包可以包含两种心法。当前快照只能用于匹配同角色同心法。

## 3. 网页匹配与本地验证

双击“启动.cmd”打开研究室网页。导入批量录像包与自己的快照，在“批量候选”中应用权重和排序。默认攻击、闪避、魂暴、魂伤各1，生命0.05，魔法0。数值按相对差距计算，不代表成功率。候选列表底部可左右滚动，选中后下方逐行显示完整差距。

选择导出份数，导出批量A/B对照JSON。游戏主城点击“导入回放/实战JSON”，选择队列，开启“回放连测开关”运行。等待完成后“导出批量结果”。结果回到网页“试验结果”导入，筛选“仅自身属性击杀”。原属性成功不代表自己的配置成功。

本地回放不提交成绩。原生面板与网页静态来源汇总分别显示，静态汇总不是最终战斗面板。未完成或终局不明确的结果不算成功。还可以在自定义属性页做本地增减试验；自定义增强属性成功也不能当作当前配置实战成功。

## 4. 成功样本转实战

网页“试验结果”中选择“实战候选（自身属性击杀）”，点击“导出选中实战操作JSON”。必须导入完整结果文件，筛选摘要不能代替完整操作。

回游戏主城，点击“导入回放/实战JSON”导入实战操作文件。人物角色、心法须一致，配置尽量保持验证时状态。点击“实战：持续预备/取消”，确认状态为持续预备开、自动重试开，再手动进入单人魔渊第九层。

失败弹窗出现约1.2秒后触发原生重新挑战按钮；成功自动关闭持续预备和重试。F9或“实战急停”随时停止两项；也有鼠标按钮，无需依赖热键。成功或急停后下一轮需要重新开启。不会自动购买次数。

实战使用服务器本局种子和当前人物，不强行使用来源种子，不替换伤害和胜利结算。种子变化可能导致失败。修改主文件与自动输入不保证不触发服务端校验。

## 5. 保留本次录像与核对

需保存某一局时先关闭自动重试，避免下一局覆盖临时内容。战斗结束后点击“停止录制并松键”，再点击“保留并导出本次”。默认不保留；新开一局或退出会丢弃未保存临时录像。

本地手动录制的胜负字段是占位值，不是服务器成绩。当前没有逐帧完整血量与Buff诊断。若要确认服务器录像更新，请重新读取榜单录像；同分可能不替换历史最佳。

## 已验证与限制

本轮测试角色（李**）悟空第二心法实战成功，约13秒。来源种子94521111，本轮实际种子16595642；33个来源按键帧与录制对应一致。同分13477后，重新读取服务器录像，确认仍保留旧种子及旧操作。本包不含个人账号、Cookie或自身快照。

以上只证明当前版本、该配置与这组操作流程可用；其他角色、技能配置及随机种子需要各自验证。示例不能直接保证通关，建议先单局试用。游戏版本更新后不要继续套用旧主文件。
