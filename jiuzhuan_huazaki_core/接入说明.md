# 花崎桜雪（预期最高分数）

来源：花崎桜雪提供的《炼丹助手1.1》源码。原始7个核心文件、权重、18条开局状态保持逐字一致，哈希见 `来源.json`。原版Node.js 24.19.0计算组件及其许可证随 `runtime/` 保留。

原始核心：`planner.mjs`、`policy.mjs`、`layout_search.mjs`、`rules.mjs`、`opening_book.mjs`、`opening_book.json`、`build_opening_book.mjs`。

新增接口：本目录 `bridge.mjs` 与上级 `jiuzhuan_huazaki.py`，仅用于状态转换、Node进程通信、完整清理后落子序列和服务器回包核验。没有改写原始选点评分或参数。

工具箱下拉框选择“花崎桜雪（预期最高分数）”。默认推荐策略保持不变。

- 目标是预期最终分数，达到45000后继续原算法，不执行其他策略的随机填满收尾。
- 保留“清理→落子”完整计划；清理后盘面不符会停止，避免在错误盘面继续计划。
- 通过原版规则按回包日志核验实际合成及药渣事件；不会因我们原算法的扫描顺序覆盖它。
- 外层仍遵守活动300秒时限、免费次数和点券保护；不购买次数。
- 尚无该策略在工具箱内的整局胜率或正式服务器测试数据。离线接口核对不能证明胜率。

分发源码时必须同时保留上级接口模块、整个 `jiuzhuan_huazaki_core/` 目录和 `runtime/node.exe`，不要只复制Python接口或planner文件。
